# 创业自检清单（郭氏口径 · 用户作业表）

> 用法：用户迷茫/纠结时，让用户自己填；填完回来一起看。原则——问题不超过 5 个/轮，一次只解决一个决策。

## 一、要不要做这个项目（谋定五问，日报 008）

1. 我有没有做这个项目的基因？（内容感？供应链？流量？）
2. 我准备花多长时间？
3. 亏了能否接受？
4. 最多预估亏多少？（写具体数字）
5. 有没有真正有结果的人带？

→ 5 问里有 3 个答不上来 = 还没到"谋定"，先去补调研（真实世界对照法：找同赛道拿到结果的 20-100 个案例拆要素，日报 387）。

## 二、市场够不够大（三维 + 算账，日报 316/295）

- 是不是国民级痛点？痛点多大？
- 我想做 / 我能做 / 我可以做，分别打几分？
- 天花板算账：需求人数 × 人均消费 = ____ 万/年
- 钱已经在哪流动了？（谁已经在为这个痛点付钱，日报 398）

## 三、验证成本清单（MVP，日报 397/380）

- 我的核心假设一句话是：______
- 最低成本验证它需要：__ 元 / __ 天
- 一次性验证的事 → 用可行解；反复使用的事 → 才配最优解
- 第一个能收钱的动作：0.99 元能测什么？（日报 380）

## 四、流量自查（日报 006/373/367）

- 我知道自己用户的"消费决策路径"长什么样吗？（搜什么词、在哪对比、看什么差评）
- 三类内容（评测/推荐/使用体验）我各有多少条？
- 我在追"注意力"还是"信任力"？爆款之后加的好友，付款了吗？
- "没有做不起来的账号，账号流量不好就是人的问题"——我的日更是每天几条？

## 五、团队自查（日报 005/095/330/370）

- 我现在的核心问题是"会死人能倒闭"级别的，还是点状琐事？
- 每个部门有 SOP 手册吗？新人第一周照着能干活吗？
- 最近一次员工出错，根因是人的问题还是流程/标准不清？
- 我在靠人，还是靠机制？（日报 351）

## 六、心态自查（日报 389/381/399/157）

- 把所有困扰写满一页纸 → 划掉"半年内不改也不会死"的 → 剩下的是：______
- 今天把自己调到开心状态了吗？
- 我卡住是因为"不懂方法"，还是因为"怕失败"？（日报 405）
- 可挣可不挣的钱、可干可不干的事、可参加可不参加的活动——我最近贪了哪一样？（日报 157）
